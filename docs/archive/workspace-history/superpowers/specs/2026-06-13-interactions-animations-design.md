# 交互与细节动效设计文档

> **日期：** 2026/06/13
> **目标：** 为博客引入轻量、克制且丝滑的 CSS 动效，提升用户的阅读节奏感与精致感，同时不破坏编辑风格的“安静”氛围。

---

## 一、设计基调

*   **克制：** 动效仅用于辅助视觉引导，时长不超过 0.5s。
*   **优雅：** 采用先快后慢的贝塞尔曲线 (`ease-out` 或 `cubic-bezier`)。
*   **轻量：** 纯 CSS 实现，无 JS 运行时负担。

---

## 二、具体设计项

### 2.1 页面平滑渐入 (Soft Page Fade-in)
*   **目标：** 消除页面切换时的突兀跳变感。
*   **作用域：** 全局 `<body>` 或核心 `<main>` 容器。
*   **设计：**
    *   动画名称：`fadeInUp`
    *   初始状态：`opacity: 0; transform: translateY(10px);`
    *   结束状态：`opacity: 1; transform: translateY(0);`
    *   时长：`0.5s`
    *   曲线：`cubic-bezier(0.16, 1, 0.3, 1)`

### 2.2 链接悬停动画 (Elegant Link Hovers)
*   **目标：** 提供更具“流动感”的交互反馈。
*   **作用域：** 文章标题、正文链接。
*   **设计：**
    *   移除默认的 `text-decoration: underline`。
    *   使用 `background-image: linear-gradient` 模拟下划线，置于文字底部。
    *   默认状态：下划线宽度为 0，或者具有低透明度的固定宽度。
    *   悬停状态：下划线宽度从左向右平滑延伸至 100%。
    *   时长：`0.3s`

### 2.3 列表序贯加载 (Staggered Reveal)
*   **目标：** 让列表呈现出如“水流”般落下的动态过程。
*   **作用域：** 首页及归档页的文章列表项 (`post-item`, `article`)。
*   **设计：**
    *   为列表项应用与页面渐入类似的 `fadeInUp` 动画。
    *   使用 CSS 选择器 `&:nth-child(n)` 自动分配递增的 `animation-delay`。
    *   步长：每个元素延迟 `0.05s`。

---

## 三、技术实现规划

1.  **定义全局 Keyframes:** 在 `global.css` 中统一定义动画的关键帧。
2.  **应用基础动画:** 将渐入动画应用到 Layout 组件的容器上。
3.  **重构链接样式:** 统一修改 `a` 标签的全局 CSS 规则。
4.  **循环注入延迟:** 在 `index.astro` 及归档页中使用简单的 CSS 循环（或在 Astro 模板中动态注入 style）实现序贯延迟。

---

## 四、回滚策略

所有变更均通过 `global.css` 的新增规则实现。如需回滚，只需移除或注释掉对应的 CSS 动画区块即可。变更将作为独立 Commit 提交。
