# 个人博客搭建方案设计

## 一、需求概述

| 需求 | 说明 |
|------|------|
| **博客性质** | 混合型：生活随笔为主（B），技术文章为辅（A） |
| **技术背景** | 计算机专业，了解 HTML/CSS，不希望运维负担 |
| **优先级** | A.写作体验 > B.简洁好看 > C.零成本 > D.可扩展 |
| **托管偏好** | 半托管（B）或完全托管（A） |
| **部署目标** | 自己的云服务器（非本机、非托管平台） |

---

## 二、技术方案

### 2.1 整体架构

```
[本地开发机]
    │
    │ Git push
    ▼
[云服务器]
    ├── Git Hook (自动拉取 + 构建)
    ├── /var/www/blog/ (静态文件)
    └── Nginx (端口 80/443)
```

### 2.2 技术栈

| 层级 | 技术选择 | 理由 |
|------|---------|------|
| 站点生成器 | Astro | 性能极佳，默认零 JS，多框架支持 |
| 内容格式 | Markdown | 写作体验好，专注内容 |
| 主题 | 成熟博客主题（如 astro-paper）+ 微调 | 简洁好看，开箱即用 |
| Web 服务器 | Nginx | 轻量、稳定、配置简单 |
| SSL | Let's Encrypt (Certbot) | 免费自动续期 |
| 域名 | 可选 | 可先用 IP 访问，后续加域名 |

### 2.3 目录结构

```
zhimin-blog/           # Astro 项目
├── src/
│   ├── content/
│   │   ├── blog/      # 技术文章 (Markdown)
│   │   └── life/      # 生活随笔 (Markdown)
│   ├── layouts/       # 页面布局
│   └── pages/         # 页面路由
├── public/            # 静态资源
├── astro.config.mjs
└── package.json

服务器端：
/var/www/blog/         # 生成的静态文件
/home/git/blog.git/    # 裸仓库
```

---

## 三、部署方式

### 3.1 Git Hook 自动部署（推荐）

1. 本地 `git push` 到服务器的裸仓库
2. 服务器 Hook 自动执行 `git pull` + `astro build`
3. 静态文件输出到 `/var/www/blog`
4. Nginx 直接服务该目录

### 3.2 Rsync 手动同步（备选）

1. 本地 `astro build`
2. `rsync -avz --delete dist/ user@server:/var/www/blog/`

## 四、主题定制

### 4.1 策略

- 使用现成主题，只微调颜色、Logo、字体
- 不从零设计，保证美观同时降低工作量

### 4.2 可定制内容

| 元素 | 定制方式 |
|------|---------|
| 颜色主题 | 配置文件或 CSS 变量 |
| 字体 | Google Fonts，替换 CSS |
| Logo | 替换图片文件 |
| 布局结构 | 修改 Layout.astro |
| 文章排版 | 修改 Markdown 样式 |

## 七、方案优势

1. **写作体验**：Markdown 创作，本地编辑，分心模式
2. **简洁好看**：使用成熟主题，专业设计，微调即可
3. **零运维负担**：Git Hook 自动部署，不用手动操作服务器
4. **零成本起步**：$30/年起，服务器费用极低
5. **可扩展**：静态站点可随时添加评论、搜索、分析

---

## 八、潜在风险与应对

| 风险 | 应对 |
|------|------|
| 服务器宕机 | 备份：本地保留源码，服务器可快速重建 |
| 流量突增 | Vultr 可随时升级套餐 |
| 域名解析问题 | 使用 Cloudflare 管理 DNS |
| 数据丢失 | Git 版本控制，本地 + 服务器双备份 |
