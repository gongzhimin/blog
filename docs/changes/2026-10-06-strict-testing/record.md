## 验证证据

环境：本机 Node v24.14.1、Playwright 1.61.0、Chromium。CI 配置已修改，未启动远程工作流，不能将本机结果写为 Node 22 或 GitHub Actions 已通过。

### 失败到通过

- 文本切分：链接 href 丢失的失败断言，修复后 text splitting 回归通过。
- 代码切分：原输出出现 `fourfive`，而预期为两行；修复后文本、换行和属性回归通过。
- 代码续页：真实浏览器独立测量得到1814px，超过221px门槛；补新页 pre 重试后同一案例通过，没有扩大容差。
- 封面收敛：全量测试曾因 book-at-last 缺失失败；受控 motion 回归稳定复现，状态观察修复后原始与受控案例通过。
- 测试发现：已登记的嵌套 spec 曾被错误接受；补执行发现约束后非法对照拒绝。
- 类型：关闭 skipLibCheck 暴露4处声明路径错误；修正后契约编译通过。非法参数夹具经格式化曾因错误注释位置失败，已将标记放到实际非法属性。
- 实际 Playwright CLI：合法对照退出0，动态跳过与预期失败均退出1；不只测试报告器的模拟返回值。

### 完整验收

`npm run verify:release` 完整执行退出0：格式、lint、契约编译、真实文档与边界扫描、测试盘点、Astro、构建、Node及Chromium均通过。Astro为0 errors、0 warnings、0 hints；Chromium为19通过、0失败、0跳过、0 flaky，retries=0。本机结果不代表远程CI已经执行。

浏览器报告固定写入根 test-results/browser-results.json；本轮早期因相对路径写入 Tooling config 下的生成报告已删除，当前报告保留。它是生成产物，不是源码或文档。

## 剩余限制

- Chromium 不证明 Safari/iOS 真机、全部字体及慢图片布局；没有性能基线或任意覆盖率百分比承诺。
- 代码案例只覆盖声明的80行输入；列表、表格、超大不可分割元素和更多富文本组合仍需独立矩阵。
- Turn.js 完整预览案例等待展开 effect 结束再移开指针；快速离开角点的所有第三方状态路径未验证。不能由该案例证明全部 hover 行为。
- 导航键碰撞、共享配置并发、资源变化重排、发布响应丢失后远程状态恢复仍有缺口。
- 公开类型编译目前重点覆盖 Site/Build；其他包的完整声明矩阵仍未建立。
- 未读取生产密钥，未提交、推送、发布或执行恢复。Q8 独立新读者走查和真实环境验收尚未完成，机器绿灯不替代这些任务。
