# 个人博客重新设计文档

> **日期：** 2026/04/13
> **目标：** 将现有 Astro 博客改造为具有编辑风格的个人博客

---

## 一、设计决策

| 项目 | 选择 |
|------|------|
| **整体风格** | 编辑风格（Editorial） |
| **内容版式** | 生活随笔与技术文章分开版式 |
| **正文字体** | Georgia（经典衬线体，打印质感） |
| **配色方案** | 暖色调 |
| **首页布局** | 简洁列表（极简时间线） |
| **关于页面** | 详细信息（头像 + 身份 + 地点 + 简介） |
| **社交链接** | 仅图标（GitHub / Twitter / Email） |
| **RSS 订阅** | 简洁文字链接 |
| **评论系统** | Giscus（基于 GitHub Discussions） |

---

## 二、配色规范

### 暖色调色板

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景色 | `#faf6f0` | 米白色，温暖纸张感 |
| 主文字色 | `#3d2b1f` | 深棕色，打印墨水感 |
| 次要文字 | `#5c4033` | 中棕色 |
| 辅助文字 | `#8b7355` | 浅棕色，日期/标签 |
| 卡片背景 | `#f5efe8` | 浅米色 |
| 强调背景 | `#e8ddd0` | 代码块背景 |
| 边框色 | `#d4c5b5` | 分隔线 |

---

## 三、字体规范

### Georgia（衬线体）

```css
/* 正文 */
font-family: Georgia, 'Times New Roman', serif;

/* 字号 */
h1: 2rem (32px)
h2: 1.5rem (24px)
h3: 1.25rem (20px)
body: 1rem (16px)
small: 0.875rem (14px)
```

## 四、首页布局

### 简洁列表结构

```
┌─────────────────────────────────────┐

│                                     │
│ 春天的午后 ············· Apr 12, 2026 │
```

- 标题 + 日期，水平排列
- 用省略号或空格填充对齐
- 或使用纯 CSS 实现两端对齐

---

## 五、内容版式

### 5.1 生活随笔版式

- 标题使用衬线体，较大字号
- 引言使用斜体
- 段落间距宽松
- 可以有诗意的排版元素

### 5.2 技术文章版式

- 标题 + 日期 + 标签
- 代码块使用深色背景（`#e8ddd0`）
- 清晰的层级结构
- 代码高亮使用暖色调

---

### 详细信息布局

- 左侧头像（56x56，圆角）
- 右侧：名字（粗体）+ 身份地点 + 简介

---

## 七、社交链接

### 仅图标布局

```
[GH] [X] [@]
```

- 深棕色背景（`#3d2b1f`）
- 白色文字
- 40x40 像素，圆角 4px
- 悬停时轻微上浮效果

---

## 八、RSS 订阅

### 简洁文字链接

```
RSS · /rss.xml
```

- 灰色文字（`#8b7355`）
- 位于页脚或文章列表底部

---

## 九、评论系统

### Giscus 配置

- 基于 GitHub Discussions
- 主题：暖色调适配
- 位置：文章底部
- 需要配置 GitHub OAuth App

---

## 十、技术实现

### 10.1 需要修改的文件

| 文件 | 操作 |
|------|------|
| `src/styles/global.css` | 添加 CSS 变量和样式 |
| `src/pages/index.astro` | 改造首页为简洁列表 |
| `src/layouts/` | 创建/修改文章布局 |
| `src/pages/about.astro` | 新建关于页面 |
| `src/content/` | 调整内容集合配置 |

### 10.2 需要安装的依赖

| 依赖 | 用途 |
|------|------|
| `@astrojs/rss` | RSS 订阅功能 |
| `astro-icon` | 社交图标 |

### 10.3 Giscus 集成

在文章页面底部添加 Giscus 组件，需要配置：
- GitHub Repository
- GitHub OAuth App Client ID / Secret

---
