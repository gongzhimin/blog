# 排版与视觉微调设计文档

> **日期：** 2026/06/13
> **目标：** 通过 CSS 微调增强博客的“沉浸式阅读”与“经典纸媒”质感，主要针对正文排版进行优化。

---

## 一、设计基调

保持现有的“沉稳内敛的编辑风格（Editorial）”，通过传统排版手法的引入，进一步弱化现代网页的工业感。

---

## 二、具体设计项

### 2.1 首字下沉 (Drop Caps)
*   **目标：** 提升文学质感。
*   **作用域：** 仅限生活随笔 (`src/layouts/LifeLayout.astro` 渲染的文章区域)。技术博客（Blog）保持原样以维持技术文档的严谨性。
*   **技术实现：** 
    *   定位文章内容区的第一个 `<p>` 标签的 `::first-letter`。
    *   设置 `float: left`，增大 `font-size` 和 `line-height`，使其占据大约 2-3 行的高度。
    *   适当调整 `padding` 和 `margin` 防止与后续文字重叠。
    *   颜色使用次要文字色（`#5c4033`）以增加层次感。

### 2.2 优雅的分隔符 (Ornamental Dividers)
*   **目标：** 替换生硬的水平实线，使用传统的排版符号。
*   **作用域：** 全局 Markdown 渲染的 `<hr>` 标签。
*   **技术实现：**
    *   去除 `<hr>` 原有的 `border`、`background`。
    *   使用 `::after` 伪元素注入文本内容 `* * *`。
    *   设置居中对齐 `text-align: center`。
    *   颜色使用辅助文字色（`#8b7355`），字号适度放大，字符间距 (`letter-spacing`) 拉开。
    *   上下预留充足的 `margin` (例如 `3rem 0`)。

### 2.3 引言块的精细化 (Refined Blockquotes)
*   **目标：** 使引用内容更具书籍感，去除常见的左侧实线样式。
*   **作用域：** 全局 Markdown 渲染的 `<blockquote>` 标签。
*   **技术实现：**
    *   移除默认的左侧边框（如果有的话）。
    *   字体样式设置为斜体 (`font-style: italic`)，颜色设置为次要文字色 (`#5c4033`)。
    *   增加左右 `margin` 使得引用块相比正文有所缩进。
    *   使用 `::before` 伪元素在左上角绝对定位注入一个大字号、低透明度的古典双引号（如 `“`），作为背景装饰。
