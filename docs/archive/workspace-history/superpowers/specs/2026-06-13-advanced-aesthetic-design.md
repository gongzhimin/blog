# 博客高级视觉重构设计文档

> **日期：** 2026/06/13
> **目标：** 将博客的视觉语言从“基础的杂志风格”提升至“极致优雅的现代极简主义”。通过字体的张力、严苛的留白控制以及材质级别的细节微调，打造高级的阅读体验。

---

## 一、 设计基调：理性的克制与感性的温度

融合瑞士国际主义排版（理性的网格与无衬线体）与传统编辑设计（感性的衬线体正文与暖色纸张质感）。

---

## 二、 核心优化模块

### 2.1 极致的字体对比 (Typography Tension)
打破全站单一衬线体的沉闷，建立强烈的字体层级：
*   **标题与正文 (Reading Text)：** 保留经典衬线体（Georgia / 时代新罗马），负责传递内容的温度和深度。
*   **元数据与导航 (Functional Text)：** 引入高度现代化的**无衬线体**（系统默认的 San Francisco / Helvetica Neue / Inter）。这部分字体将使用更小的字号（如 `0.8rem`）、全大写（Uppercase）并增加字间距（Letter-spacing），用于显示日期、"Essays" / "Technical" 分类名、返回按钮和页脚链接。
*   **效果：** 现代与古典的碰撞，产生高级排版的视觉张力。

### 2.2 严苛的网格与负空间 (Aggressive Whitespace)
告别拥挤的常规排版，引入“负空间”设计理念：
*   **行高与段距：** 增加正文的行高至 `1.8`，段落之间的间距加宽（至少 `1.5em`），让文字拥有充分的呼吸空间。
*   **列表页重构 (Index & Archives)：**
    *   取消目前的左右均等双栏。
    *   采用一种更具设计感的**非对称网格**：例如，左侧留出三分之一的空白区域（仅用于显示分类或年份），右侧三分之二区域展示文章列表。
    *   在移动端恢复为单栏，但增加各区块上下的留白（Margin）。

### 2.3 材质与边界的微调 (Subtle Material & Borders)
所有的视觉噪音必须降到最低：
*   **极细边框 (Hairline Borders)：** 移除现在的粗线条和点状虚线（Dotted border）。使用 CSS 的 `rgba` 和极小的数值（如 `0.5px` 或利用阴影模拟 1 物理像素），画出极其细腻的实线分割线，颜色使用非常浅的暖灰色。
*   **文字色彩调优：** 绝对不使用纯黑 (`#000`)。正文使用深炭灰 (`#2A2A2A`)，次要文字使用中灰带一点棕调，降低屏幕对比度带来的刺眼感，模拟真实墨水。
*   **选中态 (Selection)：** 覆盖浏览器默认的亮蓝色选中背景，使用与博客背景同色系但稍深的“高光笔”颜色（例如极浅的米黄色 `rgba(210, 190, 150, 0.4)`），连选中文字的过程都变得优雅。

## 三、 技术影响范围

本次更新将是一次深度的 CSS 和布局重构，主要修改范围：
1.  `src/styles/global.css`: 重新定义 CSS 变量、引入新字体族、重写基础元素的颜色和边框。
2.  `src/pages/index.astro`: 重写首页布局，应用新的非对称网格系统。
3.  `src/layouts/*.astro` & 归档页: 同步更新列表样式和间距。
