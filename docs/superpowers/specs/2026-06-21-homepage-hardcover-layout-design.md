# 首页精装书目录版式设计

日期：2026-06-21

## 目标

将首页内容区从现有的平装书式双页目录，调整为参考图风格的横向精装摊开书：

- 冷白纸张与可见纸张纹理。
- 浅灰色硬壳封面。
- 灰色装订布。
- 左右书口显示密集纸张边缘。
- 中央仅保留一条细中缝，并通过两侧柔和内阴影表现纸张向装订处下沉。
- 页面、导航、头部、书本和页脚在 `1440 × 900` 标准桌面视口中完整显示。

本设计只调整首页结构与视觉，不改变文章选择、分类、链接目标、主题切换或每日一句数据链路。

## 桌面区域比例

首页桌面版使用以下高度比例，合计正好为 `100%`：

| 区域 | 高度 |
| --- | ---: |
| 导航栏 | `6%` |
| 头部区 | `7%` |
| 书本内容区 | `71%` |
| 页脚区 | `16%` |

站点内容宽度为视口的 `90%`。导航、头部和页脚沿用同一条左右对齐线。

标准桌面视口目标：

- `1440 × 900` 时页面不需要滚动。
- 视口高度不足或比例异常时允许自然纵向滚动。
- 页面尺寸本身不得产生横向滚动，不以强制裁切作为主要布局手段。

## 头部

头部只保留一句：

> 写技术，也记录技术之外的生活。

删除副标题。头部标题字号令牌为 `0.5rem`，头部高度为 `7%`，使用克制的单行展示。

导航栏高度为 `6%`，导航字号令牌为 `0.4rem`。

## 书本比例

桌面版书本参数：

```json
{
  "bookWidth": "68%",
  "bookAspectRatio": 1.8,
  "paperTexture": 0.1,
  "paperColor": "#ffffff",
  "coverColor": "#f0f0f0",
  "bindingColor": "#737373"
}
```

`bookWidth` 相对于书本内容区计算。书本宽高比为 `1.8`，使书本呈现横向展开感，但左右仍保留页面留白。

书本不使用明显的左右旋转。整体只允许极轻的静态透视，以保持文字清晰。

## 书本物理结构

书本由五层组成，职责必须分离：

1. **硬壳封面**
   - 位于所有纸页之后。
   - 四周比纸页略大，颜色为 `#f0f0f0`。
   - 使用细微布纹、浅内高光和底部阴影。

2. **装订布**
   - 位于封面中央，并从纸页顶部和底部露出。
   - 颜色为 `#737373`。
   - 装订布不是页面中缝；它只在页面之外可见。

3. **左右书口**
   - 位于顶层纸页后方的左右外侧。
   - 使用 1–3px 细密竖线表现多张纸的边缘。
   - 纸层清晰但不得形成粗描边。

4. **顶层纸页**
   - 颜色为纯白 `#ffffff`。
   - 纸张纹理强度令牌为 `0.1`。
   - 纹理由极细颗粒构成，不得降低文字对比度。

5. **中央中缝**
   - 中心实体线固定为 `1px`。
   - 不存在宽的透明缝隙。
   - 通过中线两侧对称的内阴影表现纸页下沉。
   - 中线可带一条极细高光，但不得形成宽渐变柱。

## 双页目录结构

左页为生活文章，右页为技术文章。两页结构一致：

1. 页眉：左侧 `ZHIMIN`，右侧分别为 `CONTENTS`、`NOTES`。
2. 分部标签：`Part I · Life`、`Part II · Technology`。
3. 文章目录列表。
4. 底部居中的归档链接。

删除以下内容：

- “生活随笔”章节标题。
- “技术笔记”章节标题。
- 罗马数字页码。
- 另一组靠左或靠右的重复归档链接。

底部链接文案与目标：

- 左页：`全部生活文章` → `/life`
- 右页：`全部技术文章` → `/blog`

链接在各自纸页底部水平居中，使用 `archive-bottom: 10%` 和 `archive-font: 0.2rem`。

## 文章目录

目录继续显示文章标题、点线引导和日期。桌面版参数：

```json
{
  "pagePaddingInline": "7.5%",
  "pagePaddingTop": "6.5%",
  "sectionTop": "9%",
  "sectionBottom": "7%",
  "tocGap": "0.7em",
  "runningFont": "0.2rem",
  "partFont": "0.2rem",
  "tocFont": "0.2rem",
  "dateFont": "0.2rem"
}
```

日期继续使用紧凑英文书籍格式，例如 `21 JUN`。文章标题链接区域必须包含标题、点线和日期，整行均可点击。

## 字体单位

字体使用 `rem` 令牌，而不是 `px`：

- `rem` 尊重浏览器根字号和用户缩放设置。
- 正式 CSS 可使用 `clamp()` 在不同桌面尺寸间平滑调整。
- `px` 仅用于中缝、纸层细线和边框等物理细节。

本设计确认的桌面字号令牌：

```json
{
  "navFont": "0.4rem",
  "heroTitle": "0.5rem",
  "quoteFont": "0.35rem",
  "footerFont": "0.3rem",
  "runningFont": "0.2rem",
  "partFont": "0.2rem",
  "tocFont": "0.2rem",
  "dateFont": "0.2rem",
  "archiveFont": "0.2rem"
}
```

这些令牌仅用于桌面书本版式。移动端不得直接继承上述极小字号。

## 页脚

页脚高度为 `16%`，内容宽度为 `90%`。

展示顺序：

1. 英文每日一句。
2. 中文翻译。
3. 作者和版权同一行。

第三行使用双锚点布局：

- 作者沿每日一句左边线对齐。
- 版权绝对定位在页面水平中轴。
- 版权位置不受作者长度影响。

页脚字号：

- 英文每日一句：`0.35rem`
- 翻译、作者和版权：`0.3rem`

作者为空时只显示居中的版权，不保留空白作者节点。

## 移动端

移动端继续采用纵向两张纸页，不模拟完整精装摊开书：

- 隐藏硬壳、装订布、左右书口和中央中缝。
- 两页按生活、技术顺序纵向排列。
- 每页保留页眉、分部标签、前三篇文章和底部归档链接。
- 使用移动端可读字号，不继承桌面 `0.2rem` 字号。
- 不出现横向滚动。

移动端页脚恢复普通流式布局；版权不使用绝对居中，以避免窄屏文字重叠。

## 组件结构

`index.astro` 增加书本装饰层：

```html
<section class="home-book-frame">
  <div class="home-book-cover"></div>
  <div class="home-book-binding"></div>
  <div class="home-book-edge home-book-edge--left"></div>
  <div class="home-book-edge home-book-edge--right"></div>
  <section class="home-book">
    <!-- 两张 BookCatalogPage -->
  </section>
  <div class="home-book-gutter"></div>
</section>
```

`BookCatalogPage.astro` 调整为：

```html
<section class="book-page">
  <header class="book-page__running-head">...</header>
  <p class="book-page__part">...</p>
  <ol class="catalog-list">...</ol>
  <a class="book-page__archive">全部…文章</a>
</section>
```

`DailyQuote.astro` 增加 `daily-quote__meta` 容器，用于作者左对齐和版权居中。

## 测试

自动化测试至少覆盖：

- 桌面首页存在封面、装订布、左右书口和 1px 中缝装饰层。
- 桌面 `1440 × 900` 下导航、头部、整本书和页脚均在首屏内。
- 桌面页面没有横向溢出。
- 不再渲染“生活随笔”和“技术笔记”章节标题。
- 渲染 `Part I · Life` 和 `Part II · Technology`。
- 两页底部只渲染一个居中的归档链接。
- 不渲染罗马数字页码。
- 作者与版权位于同一元信息行，版权在桌面水平居中。
- 移动端隐藏书本装饰层，纸页纵向排列且字号可读。
- 现有主题切换、导航和文章链接测试继续通过。

## 非目标

- 不实现翻页、拖拽、悬停开合或书页动画。
- 不复制参考图中的图片或文字内容。
- 不把调节台加入正式网站。
- 不改变每日一句自动更新流程。
- 不重新设计归档页或文章页。
