## 范围

## 实施记录

### 设计与实施步骤

1. 在 `tests/e2e/homepage-layout.spec.mjs` 新增前后封面快速 hover/离开及扉页切片断言；旧构建须因不能恢复空闲或缺少切片而失败。
2. 在 `packages/site/src/internal/turnjs-adapter.js` 区分预览与已提交翻页；`start` 不解除闭合状态，只有 `turning` 解除。鼠标离开且没有已提交翻页或拖拽时，通过插件公开 `peel(false, false)` 取消预览；动画空闲后复原装饰与滑条。
3. 在 Site 样式生成器显式定义 `.p3` 的素材和缩放，去除纸纹伪元素；配置新增 `positions.titlePage`，封底内侧改用原素净切片。Build Schema 登记可选字段并生成参考。
4. 加强 `tests/e2e/test-pages-debug.spec.mjs`：从远端返回时核对出版说明内容、尺寸和标题绘制区域，不只核对 spread。不修改当前未复现缺陷的缓存机制。
5. 同步设计、API 和测试方案，执行完整工程、包隔离及浏览器验收；只记录实际命令和结果。

方案不选择强制重建页面：`hasPage` 是插件缓存登记，不是 DOM 连接状态。移出 DOM 后，插件会重新挂载保留的节点；已核验的第四页 HTML 在远端和返回后均保留。

### 动画阶段补充修正

用户复核指出：幻影发生在封面开合动画中，结束后消失。初次回归只覆盖闭合预览和结束状态，不能据此宣称完整动画已修复。

逐帧复现前封面 `1 -> 2`、`2 -> 1` 与后封面 `totalPages -> totalPages - 1`、反向闭合。`turning` 解除端点类后，底衬仍绘制整页矩形；`autoCenter` 已将容器移向目标位置，矩形在旋转封面背后暴露。采集的单次点击只有一次翻页提交，不是导航实际多跳一页。

先新增四个逐帧回归，再在适配器标记运动封面。运动侧的底衬和厚度装饰隐藏，另一侧保留；插件空闲后恢复端点与展开状态。不修改 vendor、不重复调用翻页、不加入中间跳页。前后封面各两个物理面的页号由当前插件总页数确定。

### 10 月 9 日内封页遮挡修正

相邻正文页预览和翻动时，封二及封底内侧的固定页包裹层为 `z-index: -1`；底衬实色在 0 层覆盖其表面。只移除实色仍会露出外部页面背景，因此同时增加书籍局部层叠隔离，并将底衬宿主改为透明，保留裁剪伪元素衬边。插件动态层级、固定页登记和已有封面运动显隐规则不变。

先执行两端内封页的截图像素回归，旧产物均失败：期望测试页颜色 `[23, 187, 83]`，实际为底衬 `[242, 241, 236]`。修正后执行像素回归、真实素材核对及全量验收；结果以本轮实际输出记录，不继承前一轮通过结论。

`npm run verify:release` 退出 0，包含完整工程检查、207 项 Node 测试、六包 tarball 隔离消费及声明验证、27 项 Chromium 测试。浏览器报告为零跳过、零失败、零 flaky；配置不允许重试。内封页像素测试覆盖预览、拖拽及正式翻页，已有封面开合逐帧回归仍通过。

按用户要求运行 `npm run dev -- --host 127.0.0.1 --port 4321`，本地地址为 `http://127.0.0.1:4321/`；当时访问成功，但后续检查进程已退出，未保留退出原因。不能保证代理终端进程跨会话持续运行；长期预览应由用户终端启动并保持打开。这不代表部署，本轮不提交或推送。真实素材的动画截图另在开发服务核对。

## 剩余限制

当前浏览器矩阵为 Chromium/WebKit；实际 Safari、触摸设备与不同 GPU 的动画需另验。多点连续截图仍不等于每帧全页绘制证明。素材切片取自受信配置，不宣称各像素在书脊处无缝；图片导出与切片尺度变化仍需视觉核对。可选 `titlePage` 缺省兼容使用 `backInside`，当前 Site 配置显式区分二者。Runtime 共享配置和 Site 全局导航仍不支持完整多实例隔离；本轮只修正固定页操作的宿主范围。
