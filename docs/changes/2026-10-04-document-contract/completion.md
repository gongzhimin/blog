# 文档契约与归属改造验收

## 范围

本轮实施全部六项要求，修改当前工程文档、专项归属、生成器、文档检查器及其测试。没有新增应用行为、提交、推送、上线或真实发布请求。当前资料统一建档，历史原件不追溯套模板；created 表示正式文档身份建立日，不冒充文件首次创建时间。

## 实施记录

| 要求        | 实施与验收落点                                                                                                                     |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 技术语言    | 按输入、输出、条件、步骤、失败、限制重写；事实审查修正 HTML 分支、移动配置字段和发布端口                                           |
| 类型结构    | 八种主要类型及辅助类型固定 H2；规范逐章定义最低内容与验收，检查器执行同一章节契约                                                  |
| 元数据      | 九字段 YAML；有效日期、状态/类型、唯一 id、关系目标、parent 文档路径与无环检查；生成参考跨日检查不改日期                           |
| 图与细节    | 总览上下文、源码依赖、目录组织、运行/部署图；六模块内部组成与关键流程图；六篇算法包含数据结构、复杂度、正确性条件和案例            |
| 模块 README | 六份各九章，独立交代用途、范围、结构、上下游、接口、例子、配置、测试与导航                                                         |
| 归属迁移    | 分页→Runtime；iOS→Publishing；服务手册/三模板→Operations；配置参考→Book Build/Site；跨模块载荷协议保留根 reference；九旧入口仅导航 |

六模块分别有 9、9、8、9、10、8 份 Markdown，包含模块 README。两个旧方案移入 archive，前两轮记录标 historical。根入口、当前历史索引、模块资料及本验收共 98 份纳入元数据检查；文件数量不是质量判据。

三组交叉审查核对非本组模块源码事实，主线复核系统图、共享制度及迁移。检查器及回归按失败→实现→通过推进；新增字段、围栏、上位关系和重复标题反例。修正章节放错位置、HTML 渲染分支、移动参数和索引重复标题，未删除原契约断言。

## 剩余限制

Mermaid 源图按实现和箭头语义审查，未新增独立视觉渲染流水线。自动工具不证明正文充分、外链可达、全部锚点或 modified 与实际差异同步；本记录不能替代未来验证。

npm 安装时报告 44 个依赖告警（3 low、11 moderate、28 high、2 critical），本轮没有强制升级或完整安全审计。发布输入限额/并发、分页资源就绪/多实例状态、原子交付、类型覆盖和真机/生产恢复仍是独立任务。

后续解耦按架构 evolution：Publishing 先分转换、transport、HTTP；Runtime 按复用压力分配置、缓存、测量和插件生命周期。没有独立消费者与版本周期前不直接拆六包。
