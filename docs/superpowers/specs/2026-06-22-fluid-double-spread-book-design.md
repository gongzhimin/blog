# 流式双开书响应式设计

日期：2026-06-22

## 目标

首页在所有窗口尺寸下始终显示双开摊开的书本。书本保持固定宽高比，在当前窗口宽度和内容区高度允许的范围内尽可能放大；窗口继续缩小时书本可以继续缩小以避免横向滚动，但每种文字到达自己的最小字号后不再缩小。

所有可调数值和显示文字继续由 JSON 管理。结构、计算规则和参数数据分离。

## 尺寸计算

书本区域拥有独立的左右间隔与上下间隔：

```text
左右间隔 = min(固定左右间隔, 视口宽度比例间隔)
上下间隔 = min(固定上下间隔, 视口高度比例间隔)
可用宽度 = 书本区域宽度 - 2 × 左右间隔
可用高度 = 书本区域高度 - 2 × 上下间隔
书本宽度 = min(可用宽度, 可用高度 × 固定宽高比)
书本高度 = 书本宽度 ÷ 固定宽高比
```

`home-page` 作为尺寸容器，书本使用 `cqw/cqh` 计算可用空间。配置模块从 `aspectRatio` 派生数值比例变量，用户不需要重复维护换算值。

## 最小尺寸语义

配置保留：

- `referenceMinimumWidth`
- `referenceMinimumHeight`

它们是设计校准参考值，不是阻止书本缩小的硬下限。低于参考尺寸后：

- 书本继续保持宽高比缩小。
- 不产生横向滚动。
- 每种文字通过自己的 `clamp()` 停在最小字号。
- 目录进入窄页或极窄页排版。

## 始终双开

不再使用移动端单页纵向堆叠方案。所有尺寸下都保留：

- 左右两张纸页。
- 硬壳封面。
- 装订布。
- 左右书口。
- 中央书脊。

移动端和窄屏仅改变书本尺寸与页内目录排版，不改变书本结构。

## 目录降级

生活页和技术页分别拥有独立目录配置，初始值可以相同，但不共享字段。

每页最多准备宽页文章数量，进入窄页后独立限制为 3 篇：

- 宽页：标题、点线和完整日期同一行。
- 窄页：标题在上，日期在下一行右对齐，隐藏点线。
- 极窄页：标题最多两行，使用紧凑日期格式。

生活页和技术页分别配置：

- 宽页最大文章数量。
- 窄页最大文章数量。
- 窄页书本宽度阈值。
- 极窄页书本宽度阈值。
- 标题最大行数。
- 宽页日期格式。
- 紧凑日期格式。
- 窄页行间距。

## 区域参数分离

布局参数按职责独立管理：

- `layout.navigation`
  - 最小、流式、最大高度。
  - 固定与比例左右留白。
  - 品牌、标题、导航之间的间距。
  - 标题隐藏阈值。
  - 主题按钮和图标尺寸。
- `layout.bookRegion`
  - 最小高度。
  - 固定与比例左右间隔。
  - 固定与比例上下间隔。
- `layout.book`
  - 固定宽高比。
  - 参考最小宽高。
  - 透视、阴影、封面、装订布、书口和中缝参数。
- `layout.lifePage`
  - 生活页内边距、Part 间距、目录间距、入口和页码位置。
- `layout.technicalPage`
  - 技术页独立的同类参数。
- `layout.footer`
  - 最小、流式、最大高度。
  - 固定与比例左右留白。
  - 上下内边距和各行间距。

## 文字参数分离

每处文字使用独立样式对象，不共享同一个参数对象。每个对象包含：

```json
{
  "fontFamily": "serif",
  "minimumSize": "0.55rem",
  "fluidSize": "1.1cqw",
  "maximumSize": "1rem",
  "lightColor": "#282522",
  "darkColor": "#ebe7df"
}
```

独立角色包括：

- 导航：品牌、标题、生活链接、技术链接、关于链接、RSS 链接。
- 生活书页：外侧页眉、内侧页眉、Part、目录标题、日期、总目录入口、页码。
- 技术书页：相同七项，但使用独立配置。
- 页脚：英文句子、中文译文、作者、版权。
- 子目录：生活目录页码、技术目录页码。

导航流式字号使用导航高度容器单位 `cqh`；书页字号使用整本书宽度容器单位 `cqw`；页脚字号使用页脚宽度容器单位 `cqw`；子目录页码可以使用视口单位。

所有字号使用：

```css
font-size: clamp(
  var(--minimum-size),
  var(--fluid-size),
  var(--maximum-size)
);
```

## 配置驱动 CSS

普通数值由 `buildHomepageCssVariables()` 生成 CSS 自定义属性。

CSS 查询条件不能直接可靠地使用自定义属性，因此以下规则由配置模块生成内联 CSS：

- 导航标题隐藏阈值。
- 生活页窄页阈值。
- 生活页极窄页阈值。
- 技术页窄页阈值。
- 技术页极窄页阈值。

Astro 只注入生成结果，不包含阈值数字。

## 数据流

```text
homepage-config.json
  ├─ 校验 → homepage-config.mjs
  ├─ CSS 变量 → body style
  ├─ 容器查询 → inline style
  ├─ 目录数量与日期格式 → homepage.mjs
  └─ 显示文字 → Astro 组件
```

## 测试

- 配置校验支持 `cqw`、`cqh` 和数值字段。
- 每个区域和每个文字角色都有独立 CSS 变量。
- 日期格式与最大文章数量由生活、技术各自配置。
- 1440×900、1366×768、1280×720、390×844、360×800 均保持双开书。
- 所有视口保持固定书本宽高比。
- 书本不产生横向滚动。
- 宽屏书本同时受宽度和高度约束，并充分利用可用空间。
- 窄屏每页最多显示 3 篇。
- 窄页隐藏点线并将日期换行。
- 极窄页显示紧凑日期。
- 各文字字号不低于自己的最小值、不高于最大值。
